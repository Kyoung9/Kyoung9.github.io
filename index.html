JS Job Scraper
GitHub

키워드 하나로 여러 채용 보드에서 일자리 찾기

여러 소스의 채용 공고를 검색하고 결과를 합친 뒤 중복을 제거해 CSV로 내보내는 작은 Flask 앱입니다. GitHub Pages에서는 정적 소개 페이지만 제공됩니다.

README 보기 exports 폴더

통합 검색

Berlin Startup Jobs, We Work Remotely, Web3.career를 한 번에 검색합니다.

중복 제거

링크 기준으로 중복을 제거하고, 링크가 없을 때는 회사/직무 기준으로 정리합니다.

CSV 내보내기

검색 결과를 CSV로 저장해 바로 공유하거나 분석할 수 있습니다.

정적 페이지는 GitHub Pages용이며, 앱 실행은 Python 환경에서 진행합니다.
